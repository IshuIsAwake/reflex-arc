Manual · calibration

Neither number is calibrated. Pulse forward, measure how far it went, and set one cell to the time that covers one grid cell. Same for the turn: adjust until a single pulse lands on a quarter turn. Every plan is driven out of these two.

The rover can only go forward and pivot anticlockwise. One motor's DIR line is faulted and spins forward whatever it is told, so any command asking it to reverse produces straight-line motion instead of a pivot — which is what turn = -1 did on the old page, and why it drove forward when the button said spin. Only turn = +1 pivots, because that asks the healthy motor to reverse. So turn = -1 is never sent from this page. A right turn is three lefts; a reversal is two lefts, a forward, then two lefts to restore the heading.
